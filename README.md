# QuickBooks AI Bookkeeping Agent

A public-safe bookkeeping automation demo that classifies transactions, recommends GL accounts, assigns confidence scores, detects exceptions, and routes uncertain items for human review.

## What it demonstrates

- transaction categorization
- merchant normalization
- project / cost-code suggestions
- confidence scoring
- duplicate and anomaly detection
- human-in-the-loop review
- bookkeeping KPI dashboard
- API-ready architecture for QuickBooks Online integrations

> All transactions and entities in this repository are synthetic. The demo does not connect to a real QuickBooks company file.

## Run

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Stack

`Python` `Streamlit` `Pandas` `Plotly` `Accounting Automation` `QuickBooks Integration Patterns`
